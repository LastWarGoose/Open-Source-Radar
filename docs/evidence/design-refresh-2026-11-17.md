# Обновление дизайна

По указанию пользователя: чёрный, белый, оранжевый; без скруглений и лишнего текста.
Удалены вступление, описания пакетов, технические объяснения и подвал. Сохранена
краткая отметка «Демо». Карточки заменены строками; управление обновлениями свёрнуто
по умолчанию, подписи сокращены. Удалён dev-индикатор Next.js.

Проверены TypeScript, production build, форматирование и существующий Playwright
сценарий: SSR, mutation, subscription, pause/reconnect. Сценарий прошёл; снимки
360×800 и 1440×1000 просмотрены, горизонтального переполнения на мобильном нет.
Встроенный браузерный host недоступен; проверка выполнена локальным Playwright.
Сайт запущен на http://localhost:3000. Backend и этапы разработки не изменены.
