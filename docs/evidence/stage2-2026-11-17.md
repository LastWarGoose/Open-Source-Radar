## Реализовано

Четыре независимых API и истории миграций `_0002`, 14 предметных таблиц:
Package, Release, DependencyRequirement, ImportJob; Repository и связи;
Vulnerability, aliases, VersionScan, findings; actors, Collection, items, Notification.
Job/outbox/receipts предыдущего этапа сохранены. FK и SQL JOIN не пересекают базы.
Общая схема проходит composition; прямой доступ Web к БД отсутствует.

Catalog использует PostgreSQL FTS simple, pg_trgm, фильтры license/hasReleases,
NAME_ASC/UPDATED_DESC и курсоры с уникальным дополнительным ключом. Вложенные
страницы ограничены. DataLoader создаётся на запрос и выполняет пакетные чтения.
Версии упорядочены через packaging.Version, требования сохраняют extras/marker/URL.

Явный синтетический seed: 108 пакетов, 114 релизов, 113 требований, два репозитория,
214 связей, один advisory с двумя идентификаторами, 110 сканирований, один finding,
две подборки (пять элементов, включая отсутствующую ссылку) и два уведомления.
Это не живой сбор. Повторный seed сохраняет количество записей.

## Найденное и границы

Проверка отсутствующей entity выявила, что простого nullable-поля недостаточно для
понятной ошибки Hive при отсутствии обязательных полей Package. Catalog теперь
явно возвращает NOT_FOUND для отсутствующей внешней ссылки; прямой root lookup
неизвестного пакета возвращает null без ошибки. Nullable-граница сохраняет подборку.

Демо этапа 0 выделено в DemoPackage/demoPackages/demoPackage и сохраняет свой
volatile сценарий mutation/subscription. Постоянный API имеет отдельные Package и
packages connection. Клиентские документы и генерируемые типы согласованы.

Нет живого импорта, 10 000 реальных пакетов, пользовательского входа/CRUD Workspace,
исполнения ImportJob, массового нагрузочного теста и production-развёртывания.
Dev-токены не являются пользовательскими сессиями. Измерение числа SELECT не
доказывает SLO. Сохраняются ограничения probe retries из решения 0002.
GitHub Actions не запускался удалённо: remote отсутствует; локальные команды и
workflow проверены. Предупреждение Starlette о будущей замене httpx на httpx2
и предупреждение Playwright NO_COLOR/FORCE_COLOR не подавлены. Этап 3 не начат.
