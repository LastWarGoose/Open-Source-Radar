## Сетевая проблема и восстановление

Первый live smoke сохранил PyPI/GitHub, но OSV получил NETWORK и отложенные задания.
Timeout воспроизведён отдельно из Windows и Linux-контейнера: системный DNS
возвращал api.osv.dev → ghs.googlehosted.com → 142.251.14.121.

HTTPS-запрос к Cloudflare DNS-over-HTTPS для того же имени вернул 172.217.208.121.
Пробный запрос из контейнера к этому адресу с исходным именем api.osv.dev и обычной
проверкой TLS дал HTTP 200 и реальные данные OSV. Для security-importer создан
локальный игнорируемый `compose.override.yaml` с extra_hosts. Общесистемный DNS,
сертификаты и проверка TLS не изменялись. Это исправление среды, не альтернативный
источник данных. IP не закреплён в переносимом compose.yaml и может измениться;
локальный override нужно обновить или удалить после исправления системного DNS.

После исправления незавершённое OSV-задание восстановилось из БД, затем два новых
полных прогона завершились успешно. Поздние ответы старых заданий не перезаписали
новую проверку.
