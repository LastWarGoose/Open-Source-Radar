## Сценарий Playwright

1. HTTP-ответ сайта содержит названия обоих репозиториев до выполнения JavaScript.
2. Страница показывает две карточки; событие содержит `fastapi/fastapi`.
3. Mutation увеличивает ревизию, query и subscription показывают новое значение.
4. Во время остановленной подписки mutation меняет query, но не последнее событие.
5. Возобновление подписки возвращает актуальную ревизию.
6. Сетевой offline/online и mutation через отдельный API-клиент восстанавливают состояние.
7. Браузерные GraphQL-запросы направлены только на gateway; ошибок JS нет.
8. На ширине 360 px нет горизонтального переполнения. Снимки 360 и 1440 px просмотрены.

## Ограничения

Два тестовых пакета, условные stars, состояние в памяти, один Catalog worker.
Подписка не хранит историю событий. БД, RabbitMQ, Redis, Celery и внешние источники
ещё не запускаются. Образы инфраструктуры следующего этапа выбраны, но не испытаны.
Демонстрационная mutation без входа доступна только через loopback-порт gateway.
Запуск предназначен для разработки на одной машине, не для внешней публикации.

TLS-загрузка Node через системные Windows-инструменты сначала не сработала.
Архив получен Python HTTPS-клиентом с проверкой TLS, SHA-256 сверена с официальным
SHASUMS256.txt; глобальные настройки TLS и PowerShell не менялись.
