# Этап 4 — публичный сайт

17 ноября 2026. Критерии этапа выполнены. Windows + Linux Docker,
Node 24.22.3, pnpm 12.21.0, Python 3.12.16, uv 0.13.7.
Рабочая копия без commit/remote. Контрольные суммы —
[stage4-source-sha256.txt](stage4-source-sha256.txt).

## Результат

Каталог `/`, карточка `/packages/[name]`, сравнение `/compare?packages=a,b,c,d`.
Стиль MDOW сохранён: тёмные панели, белый текст, оранжевые акценты, квадратные углы.
Прежняя техническая демонстрация находится на `/demo`.

Данные читаются через общий GraphQL gateway. Публичные страницы исключают
синтетические пакеты и версии. Поиск, лицензия, наличие версий, сортировка и
cursor живут в URL; возвращение назад и перезагрузка сохраняют состояние.
Карточка показывает версии, объявленные requirements, репозитории и OSV с датами.
Сравнение ограничено четырьмя пакетами, сохраняется локально и открывается по ссылке.

Сортировка stars выполняется SQL по всему набору в Catalog. Добавлена миграция
`catalog_0004`, защищённое обновление проекции, checkpoint публикации и периодическая
сверка через GraphQL. Обновления общего репозитория распространяются на связанные
пакеты. Подробности и семантика задержки: [решение 0005](../decisions/0005-public-site.md).

## Воспроизведение

После установки зависимостей и Chromium, при актуальном запущенном Compose:

```sh
docker compose build checks
uv run python -m scripts.verify_stage4
uv run python -m scripts.verify_stage3
docker compose run --rm checks
pnpm test:contract
```

`verify_stage4` временно приостанавливает импортёры и Beat, создаёт тестовые записи,
проверяет БД и браузер, последовательно отключает три подграфа. Cleanup и восстановление
сервисов выполняются в `finally`. Метки источников временных fixtures имитируют адаптеры;
они не считаются живым импортом. Никаких внешних API этот прогон не вызывает.
CI использует тот же orchestration-скрипт. Удалённый GitHub Actions не запускался:
remote отсутствует. Полный повтор инфраструктурных fault-тестов этапа 1 не выполнялся.
