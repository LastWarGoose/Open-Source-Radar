# Оформление по референсу MDOW

По просьбе пользователя текущая страница оформлена в стиле
[MDOW](https://github.com/LastWarGoose/MDOW). Просмотрены `docs/preview.png`,
`src/app/ui/design.py` и `src/app/ui/style.py` из ветки main.

Перенесены графитовый фон с точечной текстурой и мягким оранжевым свечением,
тёмные панели, тонкие рамки с угловыми акцентами, оранжевый заголовок,
шрифты Bahnschrift / Segoe UI / Consolas и оформление кнопок. Сохранены
прямые углы и минимальный текст согласно предыдущему указанию пользователя.
Белые строки каталога и крупный заголовок заменены компактными тёмными панелями.
Блок обновлений по умолчанию свёрнут. Порядок кнопок в DOM соответствует экрану.

Проверено:

- TypeScript: `pnpm typecheck` — успешно.
- Production build: `pnpm build` — успешно.
- Существующий Playwright-сценарий — 1 passed: SSR, mutation, subscription,
  пауза и восстановление после отключения сети.
- Снимки `test-results/stage0-desktop.png` (1440×1000) и
  `test-results/stage0-mobile.png` (360×800) просмотрены; горизонтального
  переполнения нет.
- Docker-образ web пересобран, контейнер healthy, сайт доступен локально
  на http://localhost:3000.

Backend и этапы разработки не изменены; полные backend-тесты не повторялись,
поскольку изменены только оформление и порядок элементов интерфейса.
Эта версия заменяет визуальное решение из `design-refresh-2026-11-17.md`.
