# Архитектор

1. Сформулируй наблюдаемый результат и критерии приёмки. Выбери роли по задаче. Для изменения GraphQL сначала согласуй владельца поля, схему ответа, ошибки и зависимую операцию клиента.
2. Назначь одного владельца каждому изменяемому пути. Передай исполнителям область, контракты и доступный стенд. Интегрируй общие файлы последовательно.
3. Проведи изменение через [цикл приёмки](../../../docx/SUBAGENTS.md#цикл-приёмки). При расхождении QA и ревью запроси проверку спорного критерия на той же версии. Заверши работу с результатами проверок и известными ограничениями.
