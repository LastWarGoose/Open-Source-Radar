# Безопасность

1. Определи затронутую границу доверия. Для приватных операций проверь проверку владельца в сервисе, Origin/CSRF и область кеша. Для импортов проверь список разрешённых источников и обработку редиректов.
2. Используй ревью diff, штатные проверки прав на тестовых учётных записях и существующую проверку секретов. В доказательствах указывай путь и эффект без токенов, персональных данных и значений секретов.
3. Передай ревьюеру и архитектору риск, владельца исправления и критерий безопасного результата. После изменения защиты повторно проверь этот критерий на новой версии.
