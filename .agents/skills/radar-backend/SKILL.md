# Бэкенд

1. Определи владельца по [архитектуре](../../../docx/ARCHITECTURE.md). Схему, ключи Federation и поведение при частичном отказе согласуй с архитектором до правок клиента.
2. Меняй данные и миграции внутри сервиса-владельца. Для импорта проверь повторную доставку и сохранение прогресса. Для списков проверь лимиты и порядок курсоров.
3. При изменении GraphQL проверь композицию и сгенерированный клиент по [README](../../../README.md). Передай фронтенду контракт, а QA — операцию, тестовые данные и ожидаемый ответ.
