# Схемы GraphQL

В каталоге лежат схемы подграфов Catalog, Repositories, Security и Workspace и составленная из них схема `supergraph.graphql`, которую загружает Hive Gateway. Исходные определения находятся в сервисах на Strawberry. Владельцы сущностей и ключи Federation описаны в [архитектуре](../../docx/ARCHITECTURE.md).

После изменения схемы выполните [команды экспорта, композиции и генерации](../../README.md#разработка-и-проверки). Именованные операции сайта находятся в `apps/web/src/*.graphql`, клиентские типы — в `apps/web/src/gql/`. CI повторяет генерацию и сверяет результат с Git.
